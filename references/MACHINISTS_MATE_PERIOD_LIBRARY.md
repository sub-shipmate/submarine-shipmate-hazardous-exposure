# Machinist's Mate Period Technical Library

**Public Reference — Information Only**

This research stream reconstructs the technical library relevant to Machinist's Mate work rather than treating every document as a military specification.

Priority document types:
- NAVPERS/NAVEDTRA rate training manuals;
- period Naval Ships' Technical Manual (NSTM) chapters;
- PMS/MIP/MRC records;
- military/federal material specifications;
- NSN/QPL/QPD product identity records; and
- period manufacturer MSDS records.

A manual describing a system or task does not establish that a particular material was used aboard a particular submarine. The intended evidence chain is:

`rating/task manual -> system technical manual -> PMS/MRC task -> required material/NSN -> product identity -> period MSDS`

Later restricted NSTM or NAVEDTRA copies are **catalog-only** unless their specific edition is authorized for public redistribution. A later restricted revision does not establish the distribution status of an earlier edition, and vice versa.
