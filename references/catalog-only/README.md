# Catalog-Only and Unverified Download References

## Public Reference — Information Only

This directory catalogs potentially useful historical, technical, occupational-health, submarine, submarine-tender, ship-repair, and hazardous-exposure references that are **not currently preserved as local document copies in this repository**.

A reference belongs here when its download, redistribution, public-release, or access status has not yet been sufficiently confirmed.

## Important Notice

A link appearing in this catalog does **not** mean the referenced document has been confirmed as authorized for downloading, copying, redistribution, or republication.

A document being viewable, searchable, indexed, or linked on the Internet does not by itself establish that this repository should redistribute a copy.

## Link Classes

- **public** — publicly reachable catalog, agency, record, or document link. Public reachability alone does not establish redistribution status.
- **authenticated** — legitimate access may require an account, credentials, or authorized service.
- **restricted** — the source or document indicates controlled/restricted distribution.
- **unknown** — access or redistribution status has not yet been established.

No credentials, cookies, tokens, private files, or instructions for bypassing access restrictions belong in this repository.

## Repository Policy

Until a document's status is reviewed, preserve only appropriate metadata and provenance here, such as title, document number/revision/date, issuing organization, record URL, document URL when appropriate, known distribution statement, research relevance, and verification notes.

Do **not** place the document itself in `../public-archive/` until suitability for public redistribution has been established.

For DoD technical information, Distribution Statement A is the normal affirmative public-release indicator. Documents marked with controlled distribution statements or other access restrictions remain catalog-only unless competent authority/public-release evidence establishes otherwise.

## Evidence Limitation

Cataloging a reference does not establish that a material was aboard a particular submarine or tender, that a sailor encountered it, an exposure route/dose/frequency, or medical causation.

## Promotion to the Public Archive

Before moving a reference into `../public-archive/`, review:

1. document identity and revision;
2. authoritative source/provenance;
3. distribution/public-release status;
4. redistribution suitability;
5. downloaded file identity and integrity;
6. destination category and manifest entry;
7. file size and cryptographic checksum.

If status remains uncertain, leave the reference catalog-only and retain the link rather than the PDF.
