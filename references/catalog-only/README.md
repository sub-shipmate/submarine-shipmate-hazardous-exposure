# Catalog-only and research registers

These CSVs are intentionally separate because they represent different evidence and distribution states.

- `reference-links.csv` — general catalog/source leads.
- `controlled-restricted-document-links.csv` — restricted/export-controlled link-only records; do not mirror these PDFs merely because a public URL exists.
- `../navy-period-material-spec-discovery.csv` — Navy/DoD specification discovery and exact-revision research.
- `../industry-msds-sds-discovery.csv` — manufacturer/product/MSDS/SDS lineage research.
- `../materials-msds-candidates.csv` — candidate materials and safety-sheet leads.
- `../material-sheet-downloads.csv` — safety-sheet acquisition tracking.
- `../research-leads.csv` — other research leads.

The generated catalog landing page links all registers and displays their current record counts.
