# Catalog-Only / Unverified Download References

This directory contains public research links for references that are not necessarily preserved as local copies.

**Current catalog records: 10**

## Status rule

A public link is not the same thing as permission to redistribute a document. `reference-links.csv` separately records the official record/source URL, direct document URL when known, download status, and redistribution status.

Entries marked `NOT AUTOMATED` or `REVIEW` must not be automatically downloaded by archive scripts. Authenticated, private, credential-bearing, restricted, export-controlled, CUI, classified, or otherwise non-public technical data must not be copied into the public archive.

## Evidence rule

A specification or SDS/MSDS establishes information about a document, material, formulation, or product. It does **not** by itself establish that the material was aboard a particular submarine, used in a particular task, or encountered by an individual.

Use the evidence path:

platform/class → ship/tender → shop/compartment → equipment → task/work package/PMS → material/product → exposure route → toxicology/medical evidence

## Controlled / restricted public links

A web-accessible PDF is not automatically authorized for redistribution. When a useful document is identified as **Distribution Statement C**, export-controlled, NOFORN, CUI, or otherwise restricted, this repository records the public record/PDF link and restriction metadata but does **not** copy the PDF into the public archive.

See `controlled-restricted-document-links.csv`.
